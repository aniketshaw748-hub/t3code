# Floating bubble

When you minimize the desktop app, a small bubble stays on top of your other windows. It shows how
many threads are running, a ring for how many have finished, and turns amber when a thread waits
for your approval or answer. Restoring the window hides it again.

- Hover the bubble to list running threads with what each is doing. Hover a thread for its last
  few steps, the step running now, and how long it has run.
- Click a thread, or the bubble itself when only one runs, to open a small chat. It shows the
  latest replies with code collapsed, lets you approve requests and send a message, and opens the
  full thread in the app.
- Drag the bubble anywhere; it snaps to the nearest side of the screen and remembers the spot.
- Threads that finish while the window is minimized stay listed, marked done or failed, until you
  restore it.

Turn it off in **Settings → General → Bubble when minimized**.
